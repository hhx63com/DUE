# DUE

A Unity project containing game assets and scripts.

## Assets

### BTM_Assets/BTM_Items_Gems
A collection of gem and item assets including:
- **Materials**: Various gem materials (Backdrop, BaseMaterial, Gradient Pallete)
- **Models**: 3D models of gems, coins, potions, keys, etc.
- **Prefabs**: Ready-to-use prefabs for all items
- **Scenes**: Sample scene showing the items
- **Scripts**: Simple animation scripts for gems

### Low Poly Christmas Pack Free
Low poly Christmas themed 3D models including snowman, Santa, gift boxes, ornaments, etc.

### Scripts
- **AudioManager.cs**: Audio management system
- **CameraController.cs**: Camera control script
- **ChaMove.cs**: Character movement script

## How to Use

1. Open this project in Unity (version 2020.3 or higher recommended)

2. To use the gem assets:
   - Navigate to `Assets/BTM_Assets/BTM_Items_Gems/Prefabs/`
   - Drag any prefab into your scene
   - Or explore the sample scene at `Assets/BTM_Assets/BTM_Items_Gems/Scenes/Gems Sample Scene.unity`

3. To use the Christmas assets:
   - Navigate to `Assets/Low Poly Christmas Pack Free/FBX/`
   - Import the models you need into your project

4. To use the scripts:
   - Copy the desired script files to your project's Assets folder
   - Attach them to appropriate GameObjects in your scene

## Requirements

- Unity 2020.3 or higher
- Universal Render Pipeline (URP) - Project Settings are configured for URP
